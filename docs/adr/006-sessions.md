# 006. Одна сессия и один run

Статус: accepted.

Повтор provision с тем же session_id идемпотентен. Другая сессия получает 409.
В одной сессии только один активный run, sandbox исполняет один exec одновременно.
Альтернатива: динамический контейнер на сессию с очередью provisioning.

Упрощение убирает маршрутизацию и гонки между пользователями. Цена: последовательный
БАФ-бенчмарк, нет многопользовательского режима. Состояние сессии в RAM;
переподключение клиента поддержано, восстановление после рестарта сервера — нет.
release требует завершения run и exec; удаляет /work, контекст и кеш идемпотентности.
