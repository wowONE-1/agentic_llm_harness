# 008. Выбор пары по БАФ

Статус: proposed для окончательного выбора пары; первый baseline измерен.

Интеграция OpenRouter позволяет менять LLM_MODEL без изменения харнеса.
Техническая совместимость API не подтверждает разрешённость модели по курсу:
перед оплатой/измерениями проверить раздел 0-1 общих правил.

Для ЧП1: одна разрешённая tool-calling модель, Б1–Б5, один повтор.
Для ЧП3: минимум три пары, например память 0/модель A, память 2/модель A,
память 2/модель B, одинаковые лимиты sandbox и фикстуры. Уточнить, засчитывает ли
курс конфигурации одного харнеса как разные пары. Все задачи, три повтора,
success rate, разброс, токены, время, затем обоснованный выбор.

Baseline 2026-11-06: текущий харнес + `nvidia/nemotron-3-ultra-550b-a55b:free`,
локальные Б1–Б5, один итоговый повтор: 5/5, 99.45с, 12 912 токенов.
Исходный вариант дал 4/5; переход к точечным правкам устранил ошибку B4.
Подробности и ограничения в `docs/baf.md`. Другие пары не сравнивались:
обоснованного выбора «лучшей модели» и проверки свойства базиса ещё нет.
Mock остаётся тестовым дублем, не кандидатом эксперимента.
