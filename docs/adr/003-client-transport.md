# 003. HTTP JSON + polling

Статус: accepted, v0.

Bearer auth, POST для операций, события через /v0/events с seq/after.
Альтернативы: WebSocket, SSE. Polling реализуется стандартной библиотекой
и позволяет переподключаться без сложного состояния соединения.

Цена: задержка до интервала polling, лишние HTTP-запросы, события пока хранятся
в памяти до release. Не предназначено для длительных многопользовательских сессий.
Открытый HTTP допустим только на localhost/через SSH-туннель; публичное развёртывание
потребует TLS и пользовательской авторизации. GUI откладывается до ЧП2.
