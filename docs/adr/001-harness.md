# 001. Свой последовательный харнес

Статус: accepted, ЧП1.

Нужен небольшой код, который можно объяснить на защите. Выбраны Python stdlib,
цикл до 8 шагов, три инструмента, последние два полных хода в промпте.
Альтернативы: готовый агентный framework, полноценная долговременная память.
Они добавляют зависимости и скрывают поведение, не нужное для первого чекпоинта.

Цена: потеря старого контекста, нет планировщика, суммаризации и параллельных вызовов.
Вариант без памяти сравнивается через MEMORY_TURNS=0 при фиксированной среде.
