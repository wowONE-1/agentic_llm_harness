# БАФ для ЧП1

Пять локальных примеров, `baf/catalog.yaml`. Файлы `.yaml` записаны как JSON —
валидное подмножество YAML 1.2, чтобы не добавлять зависимость PyYAML.
Каждый каталог содержит task.yaml, fixture, check.py.

| Задача | Что проверяет чекер | Почему атомарна |
|---|---|---|
| B1.1-port | answer.txt = 7341 | Извлечение одного значения из файла |
| B2.1-definition | Путь src/dates.py | Поиск одного определения, отличение от импорта |
| B3.1-config | Значения, типы и точные ключи JSON | Создание одного структурированного файла |
| B4.1-install | Точное содержимое README | Локальная правка без побочных изменений |
| B5.1-exit-code | answer.txt = no | Интерпретация exit code вопреки stdout OK |

Запись ответа — формат проверки, а не отдельная содержательная задача.
Проверяется итог работы агента с текстом/инструментом; сеть, сессии, изоляция
в оценку качества не входят. B5 использует сценарий с подвохом из задания.
Каталог не претендует на обязательный собственный вариант A-9: нужны ещё
свои задачи Б1–Б8, новая БАФ из трёх задач и составная задача с разложением.

`baf/runner.py` работает исключительно через клиентский HTTP-протокол.
Задачи последовательные, каждая в чистой сессии; повторов по умолчанию один.
В quality модель получает только prompt и инструменты, без smoke_calls и чекера.
В smoke модель заменена заранее заданными tool calls с готовым ответом:
проверяются доставка вызовов, изменения файлов и работа чекера, **не интеллект**.
Это scripted test double; до ЧП2 заменить smoke на разрешённую модель или настоящий
record/replay её ответов, как требует A-8.

Проверка 2026-11-06: итоговый quality-прогон на
`nvidia/nemotron-3-ultra-550b-a55b:free` — **5/5**, один повтор, 99.45 секунды,
12 912 токенов по usage API. Файл: `results/quality.jsonl`, трейсы:
`results/quality-traces.jsonl` (локальные результаты исключены из Git).

Исходный харнес проходил 4/5: B4 теряла завершающий перевод строки. Простое
напоминание о сохранении формата не помогло. В общем system prompt добавлена
рекомендация делать небольшие правки точечной заменой через Python. Финальный
прогон прошёл исходные строгие чекеры без изменения задач и ожидаемых ответов.
Это настройка на видимом наборе, а не независимая оценка на скрытых задачах.
Предыдущие прогоны сохранены как `quality-initial.jsonl`,
`quality-preserve-format.jsonl`, диагностика — `b4-diagnostic.json`.
Один успешный повтор не доказывает стабильность модели или прохождение полного базиса.
